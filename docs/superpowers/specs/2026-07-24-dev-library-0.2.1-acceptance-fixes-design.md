# Dev Workspace 0.2.1 — Dev Library 人工验收修复设计

- 日期：2026-07-24
- 状态：待书面确认
- 基线版本：Dev Library 0.2
- 目标平台：IntelliJ IDEA 2026.2 / Build 262
- 插件：Dev Workspace
- 模块：Dev Library
- 语言：Kotlin
- UI：简体中文

## 1. 目标

修复 Dev Library 0.2 首轮人工验收中发现的启动、国际化、筛选、列表、详情和来源跳转问题，使资料库达到可持续日常使用的状态。

本版本不实现 WebDAV、Git/GitHub 或自建服务器同步。

## 2. 已确认缺陷与改进项

### 2.1 启动崩溃

`LibraryPanel` 在 `init` 中调用 `createToolbar()` 时，`contextualActions` 尚未完成初始化，导致 `addAll` 的接收者为 `null`。

修复要求：

- 将 `contextualActions` 的初始化移动到 `init` 之前；
- 不改成可空；
- 不增加掩盖问题的判空；
- 检查 `LibraryPanel` 中其他被 `init` 使用、但文本顺序位于其后的属性。

### 2.2 Action 多语言失效

Tools、编辑器右键、Project View 右键和 Keymap 中显示 `%library...`。

修复要求：

- 使用 IntelliJ Action System 的资源包约定；
- `plugin.xml` 的 `<actions>` 指定 `DevWorkspaceBundle`；
- Action 不再把 `%key` 写入 `text`；
- 使用完整 Action ID 对应的：
  - `action.<id>.text`
  - `action.<id>.description`
- 验证 Tools、Find Action、Keymap、编辑器右键和 Project View 右键全部显示中文。

## 3. JSON Schema 版本升级

`library.json` 从版本 1 升级为版本 2。

```json
{
  "version": 2,
  "groups": [],
  "items": []
}
```

兼容要求：

- 版本 1 数据必须继续正常读取；
- 从版本 1 加载时，条目的 `source` 默认为 `null`；
- 保存时统一写为版本 2；
- 未知版本继续拒绝；
- 不修改既有条目 ID；
- 不修改既有 Markdown 正文文件名；
- 迁移过程必须有自动测试。

## 4. 结构化来源模型

Markdown、文件、链接等条目仍保留原有 `target` 语义。

编辑器选中文本创建的 Markdown 条目增加可选的结构化来源字段：

```kotlin
enum class LibrarySourceKind {
    EDITOR_SELECTION
}

data class LibraryItemSource(
    val kind: LibrarySourceKind,
    val path: String,
    val startLine: Int?,
    val endLine: Int?,
)
```

`LibraryItem` 增加：

```kotlin
val source: LibraryItemSource?
```

### 4.1 字段规则

- `path` 使用现有路径持久化规则；
- 项目内文件优先保存为 `${PROJECT_DIR}/...`；
- 持久化路径统一使用正斜杠；
- 行号在 JSON 和 UI 中均使用从 1 开始的编号；
- `startLine` 与 `endLine` 必须同时为空或同时存在；
- 存在时必须满足：
  - `startLine >= 1`
  - `endLine >= startLine`
- 普通 Markdown、链接、文件、图片和媒体条目允许 `source = null`；
- `source` 不替代 `target`；
- 编辑器选区生成的 Markdown 条目：
  - `target = null`
  - `source` 保存原文件路径和行范围；
  - Markdown 正文保存代码片段和来源说明。

### 4.2 打开来源

详情区点击来源时：

1. 解析 `source.path`；
2. 检查文件是否存在；
3. 使用 IDEA 编辑器打开文件；
4. 定位到 `startLine`；
5. 尽可能选中或高亮 `startLine..endLine`；
6. 将插入符移动到起始行并滚动到可见区域。

异常处理：

- 文件不存在：显示“来源文件不存在”，不抛出未处理异常；
- 行数少于原始 `startLine`：跳到文件末尾，并提示原始位置已失效；
- `endLine` 超过当前文件行数：截断到最后一行；
- 无有效项目上下文时，保留来源信息但禁用 IDEA 内跳转。

## 5. 刷新功能

工具栏增加“刷新”按钮。

刷新行为必须完整执行：

```text
重新读取三个 library.json
→ 重新读取 Markdown 正文
→ 重新检查外部文件和来源文件状态
→ 清理 Markdown 与图片预览缓存
→ 重新执行搜索与筛选
→ 保留当前筛选和尽可能保留当前选中条目
```

要求：

- 文件、图片、媒体被外部移动或删除后，手动刷新立即显示失效状态；
- 打开条目前仍再次检查路径；
- 刷新不修改任何资料；
- 刷新过程不阻塞 EDT；
- 刷新失败时显示所属作用域和错误文件。

### 6.1 筛选规则

- “全部资料”清除搜索和所有筛选；
- 每个区块的“全部”只清除该维度；
- 分组增加“全部分组”和“未分组”；
- 同名分组在合并视图按名称聚合；
- 点击同名分组时，显示三个作用域中该名称下的所有条目；
- 条目仍保留并展示自己的真实作用域；
- 不同筛选维度之间继续使用 AND；
- 同一维度多选继续使用 OR；
- 当前选中项必须有明确背景或平台选中样式；
- 区块之间使用 `TitledSeparator`、缩进和合理留白；
- 深色主题下仍可区分标题、区块标题和筛选值。

可选但推荐：

- 显示每个分组或筛选项对应的条目数量；
- 数量只反映当前搜索条件下的结果。

## 7. 中间列表改进

每条记录显示：

```text
[类型图标] 标题
           作用域 · 分组 · 标签
           说明或正文摘要
```

要求：

- Markdown、链接、文件、图片和媒体使用不同图标；
- 文件条目优先使用 IDEA 根据文件类型解析出的图标；
- 无法解析时使用通用文件图标；
- 失效路径显示警告图标或状态标识；
- 收藏仍显示星标；
- 标题、元数据和摘要形成清晰层级；
- 深色主题可读；
- 列表滚动和选择行为保持稳定。

## 9. 编辑弹窗调整

### 9.1 路径选择

“链接或路径”字段右侧增加文件夹选择按钮：

- FILE、IMAGE、MEDIA 时可选择文件；
- 选择后使用 `LibraryPathResolver.persist()` 持久化；
- LINK 不显示文件选择按钮；
- MARKDOWN 普通条目不要求路径；
- 已失效文件可直接在此字段编辑或重新选择；
- 工具栏不再提供单独重新定位。

### 9.2 标签编辑

用轻量 Tag Chip 编辑器替代仅靠逗号分隔的普通输入框。

表现：

```text
[Gradle ×] [Kotlin ×] [IntelliJ ×]  输入标签……
```

交互：

- Enter 创建标签；
- 英文逗号、中文逗号、分号可批量分隔；
- 粘贴多个标签时自动拆分；
- 点击 `×` 删除；
- 输入框为空时按 Backspace 删除最后一个；
- 去空白、去空标签、去重；
- 支持中英文输入法切换；
- 不依赖不稳定的内部 JetBrains 标签 API；
- 使用标准 Swing/IntelliJ 组件并适配主题。

## 10. 链接和路径交互

详情区的 URL、文件路径和来源位置显示为可点击样式：

- 使用平台链接色；
- 悬停显示手型光标；
- 有悬停反馈；
- URL 点击使用系统浏览器；
- 文件路径点击使用现有智能打开；
- `source` 点击使用来源跳转；
- 支持复制完整 URL、路径或来源描述。

打开前必须再次检查目标状态，不能因文件被删除而抛出未处理异常。

## 12. 快捷添加行为补充

编辑器选区：

- 生成 Markdown；
- 代码使用带语言标记的 fenced code block；
- 保存 `source.path/startLine/endLine`；
- 默认项目私有；
- 轻量确认弹窗中展示来源位置。

编辑器无选区：

- 添加当前文件；
- 使用 `target`；
- 默认项目私有。

Project View：

- 单选和多选文件继续支持；
- 图片和媒体继续自动识别；
- 不递归添加目录。

剪贴板 URL：

- 当没有显式编辑器选区或 Project View 文件选择时，快速添加读取剪贴板；
- URL 自动识别为 LINK；
- 默认全局；
- 当前仅仅存在一个已打开但没有焦点的编辑器文件，不应无条件覆盖剪贴板来源。

上下文优先级：

```text
显式编辑器文本选区
→ 显式 Project View 文件选择
→ 当前获得焦点的编辑器文件
→ 剪贴板 URL 或文本
```
