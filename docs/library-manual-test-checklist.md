# Dev Library 0.2 手动验证清单

使用前运行 `test`、`buildPlugin` 和 Terminal API 边界检查。随后以前台 `runIde` 启动沙箱，逐项记录结果。

- [ ] 创建 Markdown、链接、普通文件、图片和媒体条目。
- [ ] 验证自动类型识别与手动类型选择。
- [ ] 在全局、项目共享、项目私有三个作用域创建条目并确认全部合并显示。
- [ ] 创建跨作用域同名分组，确认视觉聚合不会丢失任一作用域的记录。
- [ ] 验证搜索、作用域/类型筛选、标签和收藏排序。
- [ ] 验证 Markdown 与图片预览。
- [ ] 验证 IDEA 编辑器、系统应用和浏览器打开策略。
- [ ] 删除或移动外部文件，验证缺失提示与重新定位。
- [ ] 验证复制、跨作用域移动和删除不会删除外部用户文件。
- [ ] 外部修改 `library.json` 和 `contents/<item-id>.md`，确认热重载。
- [ ] 破坏一个作用域 JSON，确认该作用域保留最后有效快照且其他作用域正常。
- [ ] 导出、导入 ZIP，并验证 ID 冲突处理和外部文件未进入归档。
- [ ] 检查全部 UI 为简体中文，窄工具窗口和正常 Windows 缩放下可滚动。
- [ ] 关闭项目，确认预览任务、VFS 监听器和协程均释放。
- [ ] 从 Find Action 执行“打开资料库”，确认聚焦搜索框且保留筛选、分组和选择。
- [ ] 分别从编辑器选区、当前文件、Project View 和剪贴板执行快速添加。
- [ ] 多选 Project View 文件，确认一个批量对话框可逐项审阅且目录不会递归添加。
- [ ] 保存后确认轻量通知和“查看条目”动作，且不会强制打开资料库。
- [ ] 仅修改 Markdown 正文，确认搜索正文和当前预览同时更新。
- [ ] 在 Find Action 与键位映射中找到两个动作，确认没有覆盖 IDE 默认快捷键。
